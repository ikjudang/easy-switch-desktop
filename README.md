# EasySwitch

Logitech Easy-Switch 기기를 위한 데스크톱 앱이다. 사용자는 앱에서 채널을 선택하거나, 키보드의 채널 전환에 맞춰 마우스를 함께 옮길 수 있다.

Windows와 macOS 앱을 제공한다. 아래 사용 안내는 Windows 앱을 기준으로 한다.

## 다운로드

- Windows: [단일 실행 파일](https://github.com/ikjudang/easy-switch-desktop/releases/download/v0.2.31/EasySwitch-0.2.31-win-x64.exe) · [빠른 실행 패키지](https://github.com/ikjudang/easy-switch-desktop/releases/download/v0.2.31/EasySwitch-0.2.31-fast-win-x64.zip)
- macOS: [앱 패키지](https://github.com/ikjudang/easy-switch-desktop/releases/download/macos-v0.1.5/EasySwitch-0.1.5-macos-arm64.zip) · [macOS 안내](https://github.com/ikjudang/easy-switch-desktop/tree/macos/initial-native-app/src/EasySwitch.macOS)
- 전체 배포 파일과 업데이트 안내: [GitHub Releases](https://github.com/ikjudang/easy-switch-desktop/releases)

단일 실행 파일은 내려받은 파일을 실행한다. 빠른 실행 패키지는 압축을 푼 뒤 `EasySwitch.exe`를 실행하고, 함께 풀린 폴더와 파일을 유지한다. 별도의 런타임 설치는 필요 없다.

## 처음 사용하기

1. 사용자가 키보드와 마우스를 사용할 컴퓨터·기기에 먼저 연결한다. 같은 채널이 같은 기기를 가리키도록 각 기기의 연결을 맞춘다.
2. EasySwitch를 실행한다. 앱은 연결된 Logi Bolt·Unifying 수신기와 Bluetooth 기기를 검색한다.
3. **기기 선택**에서 사용할 키보드와 마우스를 선택한다. 목록을 다시 확인하려면 이 화면의 새로고침을 사용한다.
4. 키보드의 채널 전환에 마우스가 따라가게 하려면 **설정 → 키보드 따라 마우스 전환**을 켠다.
5. 앱에서 직접 전환하려면 홈 화면, 플로팅 버튼 또는 트레이 메뉴의 채널을 선택한다.

앱은 사용자가 선택한 기기를 대상으로 동작한다. 새 기기의 최초 연결은 운영체제나 제조사의 연결 도구에서 먼저 완료한다.

## 홈과 채널

홈 화면에서 선택한 기기의 연결 상태와 전환할 채널을 확인할 수 있다. 현재 연결된 채널 표시와 마지막 전환 이력은 서로 구분한다.

채널 이름을 바꾸려면 채널을 우클릭하고, 나타난 입력칸에서 이름을 수정한 뒤 **확인**을 누른다.

## 플로팅 버튼

설정의 **플로팅 버튼** 행은 하위 설정을 펼치거나 접는다. 오른쪽 토글은 플로팅 버튼의 사용을 켜거나 끈다. 트레이 메뉴에서도 플로팅 버튼을 켜고 끌 수 있다.

- 홈 버튼을 누르면 채널 버튼과 **App** 버튼이 펼쳐진다.
- 채널 버튼은 기기 전환을 요청하고, **App** 버튼은 메인 창을 연다.
- 홈 버튼을 끌면 위치를 바꿀 수 있다.
- 홈 버튼을 길게 누르거나 우클릭한 뒤 X 구역에 놓으면 플로팅 기능이 꺼진다. 다시 사용하려면 설정이나 트레이에서 켠다.
- **하위 버튼 항상 표시**를 켜면 하위 버튼이 펼쳐진 상태로 유지된다.
- 투명도, 크기, 애니메이션 속도와 바운스 사용 여부를 설정할 수 있다.

## 트레이와 백그라운드 실행

창의 닫기·최소화는 앱을 트레이로 보낸다. 트레이 메뉴에서 창을 다시 열거나, 채널을 전환하거나, 연결 로그를 확인할 수 있다.

첫 실행에서 앱이 Windows 서비스 설치를 요청하면 사용자가 관리자 승인 창에서 설치를 허용한다. 서비스 설치 후에는 Windows 시작과 로그인에 맞춰 백그라운드 서비스와 트레이 앱이 자동으로 실행된다. 설치를 다시 시도하려면 트레이의 **로그인 전 실행 설치·업데이트**를 선택한다.

설치된 서비스는 로그인 전이나 로그아웃 상태에도 기기 감시를 유지한다. PC가 절전 중일 때는 전환을 처리하지 않으며, 절전에서 복귀하면 감시를 다시 시작한다.

트레이의 **앱 종료**는 화면 앱을 종료한다. 설치된 서비스의 따라가기 기능을 중지하려면 **키보드 따라 마우스 전환**을 끈다.

새 버전 파일을 실행하면 앱이 실행 중인 이전 버전을 교체한다. 같은 버전은 기존 창을 열고, 더 오래된 파일을 실행한 경우에는 이미 실행 중인 최신 버전을 유지한다.

## 설정과 알림

설정에서 언어, 플로팅 버튼, 마우스 따라가기, 연결 로그와 로그 자동 저장을 관리한다. 언어는 한국어와 English를 지원한다.

토스트는 기기의 연결과 채널 전환 상태를 안내한다. 이 안내는 앱이 관찰한 처리 상태이며, 다른 기기에서 실제 입력이 작동하는지는 사용자가 확인한다.

## 로그

**설정 → 연결 로그**에서 동작 기록을 확인하고, **송수신 원문 보기**와 **코드 보기**로 표시 방식을 바꿀 수 있다. 각 화면의 **내보내기**는 사용자가 고른 파일로 기록을 저장한다.

**로그 자동 저장**은 사용자가 선택한 폴더에 추가로 기록하는 기능이다. 이 설정을 꺼도 로컬 기록은 유지된다. 앱은 로그를 서버에 자동으로 업로드하지 않는다.

자세한 사용 방법은 [로그 안내](docs/public/logs.md)를 참고한다.

## 공개 소스

이 저장소에는 공개 대상 소스를 제공한다. 일부 내부 구현은 공개하지 않으므로 공개 소스만으로 전체 앱을 빌드할 수는 없다. 배포 실행 파일에는 앱 실행에 필요한 기능이 포함된다.
