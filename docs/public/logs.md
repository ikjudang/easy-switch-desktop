# 로그 보기와 내보내기

EasySwitch의 **설정 → 연결 로그**에서 연결과 전환 기록을 확인할 수 있습니다.

- 기본 화면은 연결·해제·채널 전환과 처리 결과를 보여 줍니다.
- **코드 보기**는 앱의 상태를 코드 형식으로 보여 줍니다.
- 각 화면의 **내보내기**를 누르면 사용자가 고른 파일로 해당 기록을 저장합니다.

**로그 자동 저장**을 켜면 앱이 사용자가 선택한 폴더에도 로그를 기록합니다. 이 설정을 꺼도 로컬 기록은 유지됩니다. 앱은 로그를 서버에 자동으로 업로드하지 않습니다.

코드 로그의 항목은 `|`로 나뉩니다. 스프레드시트로 가져올 때 사용자가 이 기호를 구분자로 지정할 수 있습니다.

전환 상태는 이 앱이 관찰한 결과를 뜻합니다. 다른 기기에서 키보드와 마우스 입력이 실제로 작동하는지는 사용자가 확인합니다.
