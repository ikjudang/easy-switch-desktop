# EasySwitch macOS

Logitech Easy-Switch 기기의 채널을 전환하고, 키보드의 전환에 맞춰 마우스를 함께 옮기는 macOS 앱입니다.

## 설치와 시작

[GitHub Releases](https://github.com/ikjudang/easy-switch-desktop/releases)에서 macOS 패키지를 내려받아 압축을 푼 뒤, 사용자가 `EasySwitch.app`을 응용 프로그램 폴더로 옮기고 실행합니다. 앱은 메인 창 없이 메뉴 막대에서 시작합니다. 메인 창은 메뉴 막대 아이콘을 우클릭한 뒤 **EasySwitch 열기**를 선택하면 표시됩니다.

사용자는 키보드와 마우스를 macOS 및 전환할 다른 기기에 먼저 연결합니다. 같은 채널이 같은 기기를 가리키도록 연결을 맞춘 뒤 앱의 **기기 선택**에서 사용할 키보드와 마우스를 선택합니다.

기기 접근 권한 안내가 나오면 **권한 설정 열기**를 누르고 macOS의 **개인정보 보호 및 보안 → 입력 모니터링**에서 EasySwitch를 허용합니다. 운영체제가 재실행을 요청하면 그 안내를 따른 뒤 **기기 다시 확인**을 누릅니다.

현재 패키지는 Apple Development 서명을 사용한 공개 시험판이며 공증은 완료하지 않았습니다. macOS가 실행을 제한할 수 있습니다.

## 기기 전환

홈 화면이나 플로팅 버튼의 채널을 누르면 앱이 선택한 기기의 전환을 요청합니다. 키보드의 채널 전환에 마우스가 따라가게 하려면 설정에서 **키보드 따라 마우스 전환**을 켭니다.

여러 키보드와 마우스를 선택할 수 있습니다. 설정에서 전역 단축키를 켜면 Control·Option·Command와 채널 번호 키를 함께 눌러 전환을 요청할 수 있습니다.

채널 이름은 채널의 보조 클릭 메뉴에서 바꿀 수 있습니다. 전환 상태는 토스트와 연결 로그에서 확인합니다. 다른 기기에서 실제 입력이 작동하는지는 사용자가 확인합니다. 토스트는 기기명과 상태를 나누어 왼쪽 정렬하며, 긴 기기명은 말줄임표로 표시합니다. 영어의 확인 필요 상태는 **Unconfirmed**로 표시합니다.

## 플로팅 버튼

설정의 플로팅 버튼 행은 하위 설정을 펼치거나 접으며, 토글은 플로팅 버튼의 사용을 켜거나 끕니다. 투명도, 크기, 애니메이션 속도, 하위 버튼 항상 표시와 바운스 사용 여부를 조절할 수 있습니다.

홈 버튼을 누르면 채널 버튼과 **App** 버튼이 나타납니다. 채널 버튼은 기기 전환을 요청하고 **App** 버튼은 메인 창을 엽니다. 홈 버튼을 끌어 위치를 바꾸거나 X 구역에 놓아 플로팅 기능을 끌 수 있습니다.

메뉴 막대의 EasySwitch 아이콘을 좌클릭하면 플로팅 기능이 켜집니다. 우클릭하면 앱 열기, 채널 전환, 플로팅 켜기·끄기, 마우스 따라가기, 연결 로그와 종료 메뉴가 열립니다.

## 창과 백그라운드 실행

사용자가 창을 닫거나 Dock의 **종료**를 선택해도 앱은 메뉴 막대에 남아 기기 감시를 유지합니다. 메뉴의 **EasySwitch 열기**, 실행 중인 앱 다시 열기 또는 플로팅의 **App** 버튼으로 메인 창을 다시 표시할 수 있습니다. 메뉴의 **EasySwitch 종료** 또는 **Command+Q**는 앱과 기기 감시를 완전히 종료합니다.

앱은 로그인 항목 등록을 요청할 수 있습니다. 사용자는 macOS의 로그인 항목 설정에서 자동 실행을 관리합니다. macOS 앱은 Windows의 로그인 전 실행 서비스와 별개로 동작합니다.

메인 창은 사용자가 열 때 생성하고, 닫으면 화면 자원을 해제합니다. 창을 닫아도 기기 감시와 파일 로그는 계속 동작합니다.

## 로그와 설정

설정에서 연결 로그, 코드 보기와 내보내기를 사용할 수 있습니다. **로그 자동 저장**은 사용자가 선택한 폴더에 상세 기록을 추가로 저장합니다. 로컬 기록은 유지되며 앱이 로그를 서버에 자동으로 업로드하지 않습니다.

Mac의 기본 로그는 연결·해제·채널 전환·결과와 실패 원인을 기록합니다. 일반 키 입력과 마우스 이동·클릭, 반복 송수신 원문은 기본 기록에서 제외합니다. 로그 화면의 원문 보기 버튼은 제공하지 않습니다. 기존 로그 파일은 자동으로 삭제하지 않습니다.

언어, 선택한 기기와 플로팅 설정은 앱이 보관합니다. [로그 안내](../../docs/public/logs.md)에서 화면과 내보내기 사용법을 확인할 수 있습니다.

## 시험 기능

태블릿 연동, 수신기 새 기기 등록과 로그인 전 엔진은 사용 환경별 추가 확인이 필요한 시험 기능입니다. 태블릿 연동에는 호환되는 태블릿 수신 앱이 별도로 필요하며 이 패키지에는 포함되지 않습니다. 로그인 전 엔진 사용에는 macOS의 승인이 필요합니다.

## 공개 소스와 라이선스

일부 내부 구현은 공개하지 않으므로 공개 소스만으로 전체 앱을 빌드할 수는 없습니다. 배포 앱에는 실행에 필요한 기능이 포함됩니다.

번들 글꼴의 라이선스는 배포물과 [라이선스 폴더](../../build/Assets/Licenses)에 함께 제공합니다.
